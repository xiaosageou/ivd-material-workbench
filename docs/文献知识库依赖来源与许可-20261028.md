核查日期：2026-10-28。版本以 `package.json` 与 `package-lock.json` 锁定内容为准；升级依赖时重新核对许可证和运行环境。

| 组件 | 锁定版本/协议 | 用途 | 来源 |
| --- | --- | --- | --- |

决策：不引入 LlamaIndex.TS；其官方仓库说明该项目已弃用且不再维护。[官方说明](https://github.com/run-llama/LlamaIndexTS)。Docling保留为未来 parser adapter 选项，本首版未引入其代码或模型；其代码许可证为 MIT，实际 OCR/模型许可证需在接入时另行核对。[官方仓库](https://github.com/docling-project/docling)。

Embedding连接直接走服务端 HTTP provider，便于不同 OpenAI-compatible 服务配置；API key 通过服务端环境变量提供，不写入数据库、日志或前端。Qdrant API key 同样由服务端环境变量注入。项目未配置或调用任何真实外部模型。

依赖均为独立许可证组件，不代表其自身内容或外部模型服务的使用条款已由本项目代为确认。生产部署前请根据实际锁定包检查 `node_modules/<package>/LICENSE` 并保留 SBOM/许可证扫描结果。
